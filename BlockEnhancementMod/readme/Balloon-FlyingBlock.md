# 气球与飞行块增强功能说明

本文档包含气球、方形气球和飞行块三个浮力相关方块的增强功能说明。

---

## 气球 (Balloon) 增强功能

### 概述
气球增强功能为气球方块添加了浮力动态控制、拖拽力调节等功能，实现了可编程的浮力系统。

### 功能列表

#### 1. 浮力控制系统
**效果按键** (Effect)
- 默认按键: E
- 功能: 控制气球浮力的开关

**增减浮力**
- 增加浮力: Add Speed / Add Speed Key
- 减少浮力: Reduce Speed / Reduce Speed Key
- 说明: 动态调整气球的浮力大小

**浮力变化值** (Change Speed Value)
- 范围: 可自定义
- 说明: 每次按键改变的浮力量

#### 2. 控制模式

**切换模式** (Toggle)
- 功能: 点击式开关模式
- 特性:
  - 按一次启用效果
  - 再按一次禁用效果
  - 保持当前状态

**拖拽力一起** (Together)
- 功能: 同时调节拖拽力和角拖拽力
- 特性:
  - 启用: 浮力为0时移除所有阻力
  - 禁用: 只调节浮力，保持阻力

#### 3. 浮力记忆
**最后浮力** (Last Speed)
- 功能: 记住激活前的浮力值
- 特性:
  - 禁用效果时恢复原浮力
  - 重新启用时使用记录值
  - 避免浮力突然变化

### 使用技巧

**升降气球**
```
效果按键: E
增加浮力: R
减少浮力: F
切换模式: 启用
拖拽力一起: 启用
```

**紧急降落气球**
```
效果按键: E
切换模式: 启用
拖拽力一起: 启用
```

**精确浮力控制**
```
效果按键: E
增加浮力: R
减少浮力: F
切换模式: 禁用 (按住)
拖拽力一起: 启用
```

## 方形气球 (Square Balloon) 增强功能

### 概述
方形气球增强功能为方形气球提供了与圆形气球类似的浮力控制功能，适配特殊形状的浮力需求。

### 功能列表

#### 浮力控制
- **效果按键**: 控制浮力开关
- **增加浮力**: 增加浮力量
- **减少浮力**: 减少浮力量
- **浮力变化值**: 每次变化的量

#### 控制模式
- **切换模式**: 点击/按住模式
- **拖拽力一起**: 同时调节阻力

#### 特性
- 方形气球的浮力特性与圆形略有不同
- 适合特定设计需求
- 提供相同的控制功能

### 使用技巧

**方形浮力平台**
```
效果按键: E
增加浮力: R
减少浮力: F
切换模式: 启用
拖拽力一起: 启用
```

### 功能列表

#### 基础增强
- 启用增强功能
- 支持未来扩展
- 保持兼容性

#### 特性
- 轻量级增强
- 不影响原功能

## 常见问题

### Q: 气球浮力变化不明显？
A: 解决方案：
- 增加浮力变化值
- 检查是否达到最大/最小值
- 确认效果按键正确
- 检查拖拽力设置

### Q: 气球下降速度慢？
A: 优化建议：
- 启用拖拽力一起功能
- 快速减少浮力到0
- 使用多个气球
- 增加重量

### Q: 气球上升不稳定？
A: 改善方法：
- 减小浮力变化值
- 启用拖拽力一起
- 使用切换模式
- 检查重心位置

### Q: 按键冲突？
A: 检查事项：
- 确认按键绑定正确
- 检查其他方块是否使用相同按键
- 重新映射按键
- 使用不同的按键方案

## 注意事项

1. **浮力限制**: 气球有最大和最小浮力限制
2. **阻力影响**: 拖拽力设置会影响飞行特性
3. **重心平衡**: 多气球系统需要注意重心位置
4. **按键管理**: 避免按键冲突和混淆
5. **保存设置**: 增强功能设置会保存在机器文件中
