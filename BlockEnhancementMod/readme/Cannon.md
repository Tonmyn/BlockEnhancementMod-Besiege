# 加农炮 (Cannon) 增强功能说明

## 概述

加农炮增强功能为游戏中的加农炮方块添加了自定义子弹属性、弹道轨迹显示和延迟碰撞等高级功能，显著提升了武器的精确度和可定制性。

## 功能列表

### 1. 自定义子弹系统

#### 启用自定义子弹
- **开关**: Custom Bullet / 自定义子弹
- **限制**: 仅在单人模式和非多人游戏中可用
- **弹药类型**: 仅适用于圆形炮弹 (Round)

#### 子弹物理属性

**子弹质量** (Bullet Mass)
- 范围: 0.1 - 2.0
- 默认值: 2.0
- 说明: 控制子弹的惯性
- 影响: 质量越大，动量越大，穿透力越强
- 建议: 远距离打击使用高质量，近距离使用低质量

**子弹阻力** (Bullet Drag)
- 范围: 0.01 - 0.5
- 默认值: 0.2
- 说明: 空气阻力系数
- 影响: 阻力越大，弹道下降越快
- 建议: 近距离战斗使用低阻力，远距离需考虑弹道修正

**延迟碰撞** (Delay Collision)
- 范围: 0 - 0.5 秒
- 默认值: 0.2 秒
- 说明: 子弹发射后延迟检测碰撞
- 用途:
  - 避免炮管内误判碰撞
  - 实现穿甲效果
  - 减少近距离误伤

### 2. 弹道轨迹系统

#### 启用弹道轨迹
- **开关**: Trail / 弹道轨迹
- 功能: 显示子弹飞行轨迹
- 视觉效果: 发光轨迹，便于瞄准和弹道修正

#### 轨迹参数

**轨迹长度** (Trail Length)
- 范围: 0.2 - 2.0 秒
- 默认值: 1.0 秒
- 说明: 轨迹在屏幕上停留的时间
- 建议: 长轨迹便于观察弹道，短轨迹保持画面清晰

**轨迹颜色** (Trail Color)
- 类型: 颜色选择器
- 默认: 黄色
- 说明: 自定义轨迹显示颜色
- 应用:
  - 不同武器使用不同颜色便于区分
  - 根据背景选择高对比度颜色
  - 特殊效果（如红色表示危险）

### 3. 发射控制增强

#### 无限弹药模式支持
- 功能: 在无限弹药模式下实现连续射击
- 特性:
  - 移除随机延迟
  - 实现稳定的发射频率
  - 保持自定义子弹属性

#### 射速控制
- 基于 Interval Slider 的发射间隔
- 随机延迟: 增强模式下可设为 0
- 建议: 快速射击使用自定义子弹模式

## 使用技巧

### 远程精确打击
1. 启用自定义子弹
2. 设置高质量 (1.5-2.0)
3. 低阻力 (0.1-0.15)
4. 启用弹道轨迹，使用醒目颜色
5. 根据轨迹调整仰角

### 近距离高射速
1. 使用自定义子弹
2. 低质量 (0.5-1.0) 提高射速
3. 极低阻力 (0.01-0.05)
4. 设置较长的延迟碰撞 (0.3-0.4 秒)
5. 启用弹道轨迹观察射击密度

### 穿甲效果
1. 高质量子弹 (1.8-2.0)
2. 中等阻力 (0.2-0.3)
3. 关键: 延迟碰撞设为 0 或接近 0
4. 垂直或小角度入射

### 连射压制
1. 自定义子弹 + 无限弹药
2. 低质量提高射速
3. 启用弹道轨迹形成弹幕
4. 使用不同颜色区分武器组

## 弹道计算

### 基础弹道公式
```
水平距离 = 初速度 × 发射角度的余弦 × 飞行时间
垂直距离 = 初速度 × 发射角度的正弦 × 飞行时间 - 0.5 × 重力 × 飞行时间²
```

### 阻力影响
考虑空气阻力后的弹道会下降更快，需要：
- 增加发射角度
- 提高发射功率
- 减小子弹阻力

### 延迟碰撞的应用
- **0.1-0.2 秒**: 标准设置，适合大多数情况
- **0.3-0.4 秒**: 穿甲模式，可以穿透薄装甲
- **0 秒**: 精确打击，但可能误伤近距离目标

## 常见问题

### Q: 自定义子弹不工作？
A: 检查以下几点：
- 确认弹药类型为圆形炮弹 (Round)
- 仅在单人模式可用
- 确保增强功能已启用
- 检查是否在多人游戏中

### Q: 子弹穿透力不足？
A: 尝试调整：
- 增加子弹质量到最大值
- 减小延迟碰撞时间
- 提高发射功率
- 使用垂直或小角度入射

### Q: 弹道轨迹不显示？
A: 确认：
- 启用弹道轨迹开关
- 检查轨迹长度设置（不能为 0）
- 确保使用自定义子弹模式
- 轨迹颜色可能需要调整对比度

### Q: 近距离误伤严重？
A: 解决方案：
- 增加延迟碰撞到 0.3-0.4 秒
- 调整发射角度
- 减小发射功率

### Q: 射速不如预期？
A: 优化方法：
- 降低子弹质量
- 使用无限弹药模式
- 检查 Interval Slider 设置
- 确保增强模式已启用

## 高级应用

### 弹道修正射击
1. 启用弹道轨迹
2. 进行试射观察轨迹
3. 根据轨迹调整发射角度
4. 记录有效参数组合

### 多武器协同
1. 不同武器使用不同轨迹颜色
2. 设置不同的弹道参数
3. 实现远近搭配射击
4. 形成立体火力网

### 弹幕压制
1. 多门加农炮并排布置
2. 统一参数设置
3. 稍微调整每门炮的仰角
4. 创造覆盖区域弹幕

## 注意事项

1. **性能考虑**: 同时显示过多轨迹可能影响性能
2. **多人限制**: 自定义子弹功能在多人游戏中不可用
3. **弹药类型**: 仅适用于圆形炮弹，其他类型自动禁用增强功能
4. **保存兼容性**: 自定义子弹设置会保存在机器文件中
5. **物理一致性**: 极端的物理参数可能导致不真实的弹道
