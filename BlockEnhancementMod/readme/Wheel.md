# 轮子 (Wheel) 增强功能说明

## 概述

轮子增强功能为游戏中的各种轮子（大轮、小轮、动力轮、无动力轮）添加了自定义碰撞体、摩擦力调节和弹力设置等功能，极大地提升了车辆性能和操控性。

## 功能列表

### 1. 碰撞系统

#### 启用自定义碰撞体
- **开关**: Custom Collider / 自定义碰撞体
- 功能: 使用基于网格的自定义碰撞体替代默认的盒状碰撞体
- 优势:
  - 更真实的轮子形状
  - 更好的地形适应性
  - 更精确的物理模拟

#### 显示碰撞体
- **开关**: Show Collider / 显示碰撞体
- 功能: 在游戏中显示碰撞体的红色轮廓
- 用途:
  - 调试碰撞体位置
  - 检查碰撞体大小
  - 可视化物理模拟

#### 碰撞开关
- **开关**: Collision / 碰撞
- 功能: 启用或禁用轮子的碰撞检测
- 特殊用途:
  - 创建无碰撞轮子用于视觉效果
  - 特殊机械装置设计
  - 调试物理问题

### 2. 物理属性

#### 摩擦力 (Friction)
- 范围: 0.1 - 3.0
- 默认值:
  - 轮子: 0.6
  - 大轮: 0.8
  - 无动力轮: 1.0
  - 大无动力轮: 1.0
- 说明: 控制轮子与地面的摩擦力
- 影响:
  - 高摩擦力: 抓地力强，但阻力大
  - 低摩擦力: 抓地力弱，但速度快
- 应用:
  - 越野车辆: 高摩擦力 (1.5-2.0)
  - 赛道车辆: 中等摩擦力 (0.8-1.2)
  - 漂移车辆: 低摩擦力 (0.3-0.6)
  - 特种车辆: 极低摩擦力 (0.1-0.3)

#### 弹力 (Bounciness)
- 范围: 0 - 1.0
- 默认值: 0 (无弹力)
- 说明: 控制轮子的弹性
- 应用:
  - 0: 标准轮胎，无弹性
  - 0.1-0.3: 轻微弹性，缓冲震动
  - 0.4-0.6: 中等弹性，越障性能好
  - 0.7-1.0: 高弹性，特殊用途

### 3. 马达控制增强

#### 自动制动优化
- 功能: 当马达输入为 0 时自动禁用马达
- 优势:
  - 减少不必要的物理计算
  - 改善滑行效果
  - 更真实的车辆行为

#### 唤醒物理
- 功能: 持续唤醒轮子的刚体物理
- 作用: 确保轮子始终响应物理模拟
- 适用: 精确控制的机械装置

## 适用轮子类型

该增强功能适用于以下轮子类型：

| 轮子类型 | BlockType ID | 特殊说明 |
|---------|-------------|---------|
| 小轮 | Wheel | 标准尺寸，平衡性能 |
| 大轮 | LargeWheel | 大尺寸，越野能力强 |
| 无动力小轮 | WheelUnpowered | 无马达，仅起支撑作用 |
| 无动力大轮 | LargeWheelUnpowered | 大尺寸支撑轮 |

### 轮子参数预设

系统为每种轮子类型提供了默认的位置、缩放和摩擦力参数：

#### 小轮 (Wheel)
- 位置偏移: (0, 0, 0.175)
- 缩放比例: (0.98, 0.98, 1.75)
- 默认摩擦力: 0.6
- 默认弹力: 0

#### 大轮 (LargeWheel)
- 位置偏移: (0, 0, 0.45)
- 缩放比例: (1.38, 1.38, 3.75)
- 默认摩擦力: 0.8
- 默认弹力: 0

#### 无动力小轮 (WheelUnpowered)
- 位置偏移: (0, 0, 0.175)
- 缩放比例: (0.98, 0.98, 1.75)
- 默认摩擦力: 1.0
- 默认弹力: 0

#### 无动力大轮 (LargeWheelUnpowered)
- 位置偏移: (0, 0, 0.45)
- 缩放比例: (1.38, 1.38, 1.75)
- 默认摩擦力: 1.0
- 默认弹力: 0

## 使用技巧

### 越野车辆
1. 启用自定义碰撞体
2. 高摩擦力设置 (1.5-2.0)
3. 低弹力设置 (0.1-0.3)
4. 使用大轮提高越障能力

### 赛道车辆
1. 标准或自定义碰撞体
2. 中等摩擦力 (0.8-1.2)
3. 零弹力设置 (0)
4. 优化马达控制

### 漂移车辆
1. 低摩擦力设置 (0.3-0.6)
2. 零弹力设置 (0)
3. 可选禁用部分轮子的碰撞

### 坦克车辆
1. 高摩擦力设置 (1.8-2.5)
2. 零弹力设置 (0)
3. 使用无动力轮作为履带支撑
4. 多轮组设计

### 特种车辆
1. 根据需要调整摩擦力
2. 可能需要高弹力 (0.4-0.8)
3. 考虑使用无碰撞轮子

## 常见问题

### Q: 自定义碰撞体效果不明显？
A: 可能原因和解决方案：
- 确认已启用自定义碰撞体开关
- 检查显示碰撞体是否启用以查看效果
- 某些地形类型可能不适合自定义碰撞体
- 考虑调整轮子大小

### Q: 轮子打滑严重？
A: 优化建议：
- 增加摩擦力值
- 减小马达功率
- 使用更大的轮子
- 增加重量分布到驱动轮

### Q: 车辆操控性差？
A: 改善方法：
- 调整前后轮摩擦力差异
- 使用不同尺寸的轮子
- 优化马达控制设置
- 考虑悬挂系统的配合

### Q: 轮子穿模现象？
A: 解决方案：
- 禁用自定义碰撞体
- 调整轮子位置偏移
- 减小车重或增加刚度
- 检查地形是否过于复杂

### Q: 性能下降？
A: 优化建议：
- 禁用显示碰撞体
- 减少轮子数量
- 使用标准碰撞体
- 简化车辆结构

## 高级应用

### 全地形车辆
1. 可变摩擦力设计
2. 使用大轮增加通过性
3. 结合悬挂系统
4. 多轮组布局

### 悬挂系统配合
1. 轮子摩擦力与悬挂刚度配合
2. 弹力与弹簧阻尼协调
3. 确保物理稳定性
4. 优化重量分布

### 差速器模拟
1. 内侧轮子较低摩擦力
2. 外侧轮子较高摩擦力
3. 转向时动态调整
4. 实现自然转向特性

### 特殊地形适应
1. 冰雪地形: 低摩擦力 (0.2-0.4)
2. 泥泞地形: 高摩擦力 (2.0-3.0)
3. 岩石地形: 高摩擦力 + 高弹力
4. 平坦赛道: 中等摩擦力 (0.8-1.2)

## 注意事项

1. **物理一致性**: 极端的摩擦力设置可能导致不真实的物理行为
2. **性能影响**: 自定义碰撞体可能增加计算负担
3. **稳定性**: 高弹力设置可能导致车辆不稳定
4. **兼容性**: 不同轮子类型的参数可能需要分别调整
5. **保存设置**: 增强功能的设置会保存在机器文件中

## 与其他方块配合

### 与悬挂配合
- 轮子摩擦力影响悬挂效果
- 弹力与弹簧阻尼协调
- 共同决定车辆稳定性

### 与转向配合
- 转向轮通常使用较低摩擦力
- 后驱动轮使用较高摩擦力
- 实现良好的转向特性

### 与刹车配合
- 高摩擦力轮子刹车效果好
- 可选使用不同摩擦力的轮子
- 实现差速刹车效果
