## 截屏工具推荐

### Windows系统
1. **Windows截图工具** (Win+Shift+S)
   - 内置工具，无需安装
   - 支持矩形、窗口、全屏截图
   - 自动保存到剪贴板

2. **OBS Studio**
   - 专业录屏软件
   - 支持高质量截图
   - 可设置快捷键

3. **Steam截图**
   - Steam自带截图功能 (F12)
   - 自动保存到Steam文件夹
   - Besiege游戏内置支持

## 截屏技巧

### 🎯 基本技巧
1. **选择合适场景**: 选择干净、背景简单的场景
2. **展示关键功能**: 确保截图能清晰展示要说明的功能
3. **保持一致性**: 同一系列截图使用相似的视角和比例
4. **标注清晰**: 可以在截图上添加文字标注说明重点

### 📐 技术参数
- **分辨率**: 建议 1920x1080 或更高
- **格式**: PNG (无损) 或 JPG (较小)
- **命名**: 使用有意义的文件名，如 `rocket-guidance-01.png`

### 🖼️ 构图建议
1. **突出主体**: 方块功能在画面中央或明显位置
2. **适当留白**: 不要画面太满，留出说明文字空间
3. **对比强烈**: 效果对比要明显，如开启/关闭功能
4. **包含参照物**: 可以加入已知尺寸物体作为参照

## 后期处理建议

### 图片处理工具
1. **Paint.NET** - 免费轻量级图像编辑器
2. **GIMP** - 免费开源图像编辑器
3. **Photoshop** - 专业图像编辑软件

### 处理建议
1. **调整亮度**: 确保图片清晰明亮
2. **添加标注**: 用箭头或文字标注重点
3. **裁剪优化**: 去除不必要的边缘
4. **压缩优化**: 在保持质量的前提下减小文件大小
