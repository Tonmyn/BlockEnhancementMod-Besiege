# 其他方块增强功能说明

本文档包含蒙皮块、摩擦垫以及其他方块的增强功能说明。

---

## 蒙皮块 (Build Surface) 增强功能

### 概述
蒙皮块增强功能为蒙皮方块添加了透明支撑、运动学模式、关节半径调节等功能，提供了更多的结构选项。

### 功能列表

#### 1. 运动学模式
**运动学** (Kinematic)
- 开关: Kinematic
- 功能: 将蒙皮块设置为运动学物体
- 特性:
  - 不受物理影响
  - 可以被脚本移动
  - 不会对其他物体产生物理影响
- 应用:
  - 固定结构
  - 装饰性部件
  - 特殊机械装置

#### 2. 透明支撑
**透明支撑** (Transparent Support)
- 开关: Transparent
- 功能: 使蒙皮块变为半透明
- 特性:
  - 视觉效果改变
  - 保持物理属性
  - 仅适用于特定材质
- 限制:
  - 默认材质 (Visual Value = 0) 不可用
  - 需要特定皮肤类型
  - 透明度可调节

#### 3. 关节半径
**关节半径** (Joint Radius)
- 范围: 0.1 - 1.0
- 默认值: 1.0
- 说明: 调节连接关节的影响范围
- 影响:
  - 大值: 连接范围大，稳定性好
  - 小值: 连接范围小，灵活性高
- 应用:
  - 稳定结构: 大半径 (0.8-1.0)
  - 灵活结构: 小半径 (0.1-0.4)

### 使用技巧

**固定蒙皮结构**
```
运动学: 启用
透明支撑: 禁用
关节半径: 1.0
```

**透明装饰蒙皮**
```
运动学: 禁用
透明支撑: 启用
关节半径: 0.5
```

**灵活连接蒙皮**
```
运动学: 禁用
透明支撑: 禁用
关节半径: 0.2
```

## 摩擦垫 (Grip Pad) 增强功能

### 概述
摩擦垫增强功能为摩擦垫方块添加了摩擦力调节和硬度设置等功能，提供了精确的抓地力控制。

### 功能列表

#### 1. 摩擦力控制
**摩擦力** (Friction)
- 范围: 0 - 5.0
- 默认值: 1.0
- 实际摩擦力: 值 × 1000
- 说明: 控制摩擦垫与地面的摩擦力
- 影响:
  - 高值: 极强抓地力，难以滑动
  - 低值: 较弱抓地力，容易滑动
- 应用:
  - 爬坡: 高摩擦力 (3.0-5.0)
  - 漂移: 低摩擦力 (0.5-1.5)
  - 标准: 中等摩擦力 (1.5-2.5)

#### 2. 硬度系统
**硬度菜单** (Hardness)
- 选项: 木头硬度等级
- 功能: 调节摩擦垫的结构强度
- 影响:
  - 高硬度: 不易损坏，但可能传递更多震动
  - 低硬度: 有弹性，可缓冲冲击
- 应用:
  - 重型机械: 高硬度
  - 减震系统: 低硬度

### 使用技巧

**高抓地力摩擦垫**
```
摩擦力: 4.0-5.0
硬度: 高
```

**漂移摩擦垫**
```
摩擦力: 0.5-1.0
硬度: 中等
```

**标准摩擦垫**
```
摩擦力: 2.0-3.0
硬度: 中等
```

## 装甲 (Armor) 增强功能

### 概述
装甲增强功能为装甲方块添加了监视器功能，可以在装甲表面显示摄像机画面。

### 功能列表

#### 1. 监视器系统
**频道菜单** (Channel Menu)
- 功能: 选择要显示的摄像机频道
- 特性:
  - 自动检测场景中的摄像机
  - 动态更新频道列表
  - 支持频道切换

**切换频道** (Change Channel)
- 默认按键: C
- 功能: 切换到下一个可用频道
- 特性:
  - 循环切换
  - 快速访问不同视角

**开关** (Switch)
- 默认按键: E
- 功能: 开关监视器显示
- 特性:
  - 快速隐藏/显示
  - 节省性能

#### 2. 画面设置
**宽度像素** (Width Pixel)
- 范围: 0 - 1920
- 默认值: 800
- 说明: 监视器画面的宽度分辨率

**高度像素** (Height Pixel)
- 范围: 0 - 1080
- 默认值: 800
- 说明: 监视器画面的高度分辨率

### 使用技巧

**标准监视器**
```
频道: 自动选择
宽度像素: 800
高度像素: 800
```

**高清监视器**
```
频道: 自动选择
宽度像素: 1920
高度像素: 1080
```

**低功耗监视器**
```
频道: 自动选择
宽度像素: 400
高度像素: 400
```

## 常见问题

### Q: 蒙皮块透明功能不工作？
A: 检查事项：
- 确认使用了非默认皮肤
- 检查透明支撑开关
- 验证材质是否支持
- 尝试不同的皮肤类型

### Q: 摩擦垫抓地力不足？
A: 解决方案：
- 增加摩擦力值
- 检查表面材质
- 增加摩擦垫数量
- 优化重量分布

### Q: 监视器无画面？
A: 确认：
- 场景中有摄像机
- 频道选择正确
- 分辨率设置合理
- 摄像机正常工作

### Q: 关节连接不稳定？
A: 优化建议：
- 调整关节半径
- 检查连接方式
- 增加结构强度
- 优化重量分布

## 注意事项

1. **性能考虑**: 高分辨率监视器可能影响性能
2. **透明限制**: 透明支撑仅适用于特定材质
3. **摩擦力平衡**: 极端的摩擦力设置可能导致物理异常
4. **保存设置**: 增强功能设置会保存在机器文件中
5. **过时方块**: 某些方块已标记为过时，建议使用替代方案
