# 特殊武器方块增强功能说明

本文档包含喷火器、水炮和分离铰链三个特殊武器方块的增强功能说明。

---

## 喷火器 (Flamethrower) 增强功能

### 概述
喷火器增强功能为喷火器方块添加了推力设置和火焰颜色自定义等功能，使其兼具攻击和推进双重功能。

### 功能列表

#### 1. 推力系统
**推力** (Thrust Force)
- 范围: 0 - 5.0
- 默认值: 0
- 实际推力: 值 × 100
- 说明: 喷火器产生的反向推力
- 特性:
  - 仅在喷火时产生推力
  - 推力方向为火焰反方向
  - 可用于飞行推进

#### 2. 火焰视觉

**火焰颜色** (Flame Color)
- 类型: 颜色选择器
- 默认: 白色
- 说明: 自定义火焰颜色
- 特性:
  - 使用 additive shader
  - 颜色可实时改变
  - 支持全色谱

**火焰着色器**
- 默认: Particles/Additive
- 说明: 火焰粒子使用的着色器
- 特性: 加法混合，发光效果

### 使用技巧

**火焰推进器**
```
推力: 3.0-5.0
火焰颜色: 橙红色
```

**装饰性喷火器**
```
推力: 0-0.5
火焰颜色: 自定义
```

**战术喷火器**
```
推力: 1.0-2.0
火焰颜色: 黄色
```

### 推力计算
```
实际推力 = 推力设置值 × 100
方向 = 火焰喷出方向的相反方向
持续时间 = 喷火持续时间
```

## 水炮 (Water Cannon) 增强功能

### 概述
水炮增强功能为水炮方块添加了沸腾模式，使其具有特殊的攻击效果。

### 功能列表

#### 沸腾模式
**沸腾** (Boiling)
- 开关: Boiling / 沸腾
- 功能: 将水炮改为喷射高温蒸汽
- 特性:
  - 水流变为蒸汽
  - 具有燃烧效果
  - 可以点燃目标
- 影响:
  - 攻击范围可能变化
  - 视觉效果不同
  - 伤害特性改变

### 使用技巧

**标准水炮**
```
沸腾: 禁用
```

**蒸汽炮**
```
沸腾: 启用
```

**特殊用途水炮**
```
沸腾: 可选启用
根据需要切换
```

## 分离铰链 (Decoupler) 增强功能

### 概述
分离铰链增强功能为分离铰链方块添加了爆炸力和扭矩调节功能，使其成为可控的分离系统。

### 功能列表

#### 1. 爆炸力控制
**爆炸力** (Explode Force)
- 范围: 0 - 3000
- 默认值: 1000
- 说明: 控制分离时的爆炸推力
- 影响:
  - 高值: 强烈分离，快速分开
  - 低值: 温和分离，缓慢分开
- 应用:
  - 火箭级间分离: 高值 (2000-3000)
  - 载荷投放: 中值 (1000-1500)
  - 温和分离: 低值 (500-1000)

#### 2. 爆炸扭矩控制
**爆炸扭矩** (Explode Torque)
- 范围: 0 - 2500
- 默认值: 2000
- 说明: 控制分离时的旋转扭矩
- 影响:
  - 高值: 剧烈旋转
  - 低值: 轻微旋转
- 应用:
  - 定向分离: 中等扭矩
  - 任意分离: 低或零扭矩
  - 特殊旋转分离: 高扭矩

### 使用技巧

**火箭级间分离**
```
爆炸力: 2500-3000
爆炸扭矩: 1500-2000
```

**载荷投放**
```
爆炸力: 1200-1500
爆炸扭矩: 500-1000
```

**温和分离**
```
爆炸力: 500-800
爆炸扭矩: 0-300
```

**剧烈分离**
```
爆炸力: 2800-3000
爆炸扭矩: 2000-2500
```

## 常见问题

### Q: 喷火器推力效果不明显？
A: 解决方案：
- 增加推力值
- 确保喷火器在喷火状态
- 检查车辆重量
- 确认推力方向正确

### Q: 火焰颜色不显示？
A: 检查事项：
- 确认颜色已设置
- 检查着色器是否正确
- 验证增强功能已启用
- 尝试不同的颜色值

### Q: 水炮沸腾模式不工作？
A: 确认：
- 沸腾开关已启用
- 水炮正在喷射
- 检查增强功能状态
- 验证物理效果

### Q: 分离铰链不分离？
A: 解决方案：
- 确认已触发分离
- 检查爆炸力设置
- 验证连接是否牢固
- 检查其他约束

### Q: 分离时旋转过大？
A: 优化建议：
- 降低爆炸扭矩值
- 调整连接位置
- 使用多个分离点
- 考虑添加稳定器

## 注意事项

1. **推力平衡**: 喷火器推力可能导致车辆失衡
2. **颜色兼容**: 某些颜色可能在不同环境下效果不佳
3. **沸腾效果**: 沸腾模式会改变水炮特性
4. **爆炸安全**: 分离铰链的爆炸力可能影响其他结构
5. **保存设置**: 增强功能设置会保存在机器文件中
