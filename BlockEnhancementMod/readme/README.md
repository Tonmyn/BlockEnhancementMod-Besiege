# BlockEnhancementMod

## 简介

BlockEnhancementMod 是一个为 Besiege 游戏开发的功能扩展模组，旨在增强游戏中各种方块的功能，提供更多的自定义选项和高级特性。该模组为原有的游戏方块添加了大量进阶属性和功能，使玩家能够构建更加复杂和精细的机械装置。

## 功能特点

### 方块功能扩展

模组为以下游戏方块提供了进阶功能扩展：

#### 武器系统
- **火箭** - 导弹制导、弹道预测、近炸引信、高爆模式、烟雾效果自定义
- **加农炮** - 自定义子弹属性、弹道轨迹、延迟碰撞
- **十字弩** - 基础功能扩展

#### 移动系统
- **轮子** - 自定义碰撞体、摩擦力调节、弹力设置
- **小轮** - 小型轮子的进阶设置
- **无动力轮** - 无动力轮的摩擦力调节
- **无动力齿轮** - 齿轮的物理属性调整
- **齿轮** - 齿轮控制器增强
- **螺旋桨** - 螺旋桨控制器增强

#### 连接系统
- **铰链** - 弹簧铰链功能
- **转向铰链** - 转向控制增强
- **活塞** - 硬度调节、阻尼设置、行程限制
- **滑块** - 硬度调节、锁定功能（已过时）
- **弹簧** - 阻力调节
- **球关节** - 物理属性增强
- **分离铰链** - 爆炸力和扭矩调节

#### 特殊功能方块
- **摄像机** - 目标跟踪、自动锁定、视角控制
- **气球** - 浮力控制、拖拽力调节
- **方形气球** - 方形气球的特殊功能
- **飞行块** - 飞行控制
- **蒙皮块** - 透明支撑、运动学模式、关节半径
- **摩擦垫** - 摩擦力调节、硬度设置
- **悬挂** - 液压模式、硬度调节、伸缩限制
- **喷火器** - 推力设置、火焰颜色自定义
- **水炮** - 沸腾模式
- **自转块** - 旋转锁定（已过时）
- **转向块** - 转向限制
- **木块** - 材质属性
- **装甲** - 摄像机监视功能

### 通用特性

1. **模块化设计** - 每个方块都有独立的增强功能，可单独启用或禁用
2. **详细配置** - 提供滑块、开关、按键等多种配置选项
3. **语言支持** - 支持多语言界面（包括中文）
4. **命令系统** - 内置控制台命令用于高级调试和配置
5. **在线兼容** - 支持多人联机游戏

## 安装方法

### 自动安装

1. 下载最新的 BlockEnhancementMod 模组文件
2. 将文件放置到 Besiege 游戏目录的 `Besiege_Data\Mods\` 文件夹中
3. 启动游戏，模组将自动加载

### 手动安装

1. 编译模组项目生成 `BlockEnhancementMod.dll`
2. 将 DLL 文件复制到 `Besiege_Data\Mods\BlockEnhancementMod\` 目录
3. 将 `Resources` 文件夹内容复制到 `Besiege_Data\Mods\BlockEnhancementMod\Resources\`
4. 将 `XML` 文件夹内容复制到 `Besiege_Data\Mods\BlockEnhancementMod\`
5. 启动游戏

## 使用说明

### 基本使用

1. 在建筑模式下选中任意方块
2. 在方块属性面板中找到 "Enhancement" 或 "增强" 开关
3. 启用增强功能后，将显示额外的配置选项
4. 根据需要调整各项参数

### 控制台命令

模组提供了以下控制台命令（在游戏控制台中输入 `be help` 查看）：

```
be srsecon [value]      - 设置火箭烟雾发射率
be srsl [value]         - 设置火箭烟雾持续时间
be srss [value]         - 设置火箭烟雾大小
be srssc [r g b]        - 设置火箭烟雾起始颜色
be srsec [r g b]        - 设置火箭烟雾结束颜色
be srssct [value]       - 设置火箭烟雾起始颜色时间
be srsect [value]       - 设置火箭烟雾结束颜色时间
be srssa [value]        - 设置火箭烟雾起始透明度
be srsea [value]        - 设置火箭烟雾结束透明度
be srssat [value]       - 设置火箭烟雾起始透明度时间
be srseat [value]       - 设置火箭烟雾结束透明度时间
be srf [value]          - 设置雷达频率
be rfa                  - 刷新资源文件
be setgap [value]       - 设置全局音频音调 (0-2)
```

## 配置文件

模组通过 `Configuration.cs` 和 `ModSetting.cs` 管理配置，支持：

- 火箭烟雾效果参数
- 雷达系统参数
- 音效资源加载
- 全局设置选项

## 常见问题

### Q: 模组不工作怎么办？
A: 请确保：
- DLL 文件已正确放置在 Mods 文件夹中
- 游戏版本与模组兼容
- 其他模组没有冲突

### Q: 如何重置方块设置？
A: 在方块属性面板中禁用增强功能，然后重新启用即可恢复默认值。

### Q: 支持多人游戏吗？
A: 是的，模组支持多人联机，但某些高级功能可能仅在主机端生效。
