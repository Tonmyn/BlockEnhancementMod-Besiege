# 机械连接方块增强功能说明

本文档包含活塞、弹簧、铰链三个机械连接方块的增强功能说明。

---

## 活塞 (Piston) 增强功能

### 概述
活塞增强功能为活塞方块添加了硬度调节、阻尼设置和行程限制等功能，提供了更精确的控制和更强的机械性能。

### 功能列表

#### 1. 硬度系统
**硬度菜单** (Hardness)
- 选项: 金属硬度等级
- 功能: 调节活塞的结构强度
- 影响:
  - 高硬度: 不易断裂，但可能传递更多震动
  - 低硬度: 有弹性，可吸收冲击
- 应用:
  - 重型机械: 高硬度
  - 减震系统: 低硬度

#### 2. 阻尼控制
**阻尼** (Damper)
- 范围: 0 - 5.0
- 默认值: 1.0
- 说明: 控制活塞运动的阻尼系数
- 影响:
  - 高阻尼: 运动缓慢，稳定
  - 低阻尼: 运动快速，可能震荡
- 应用:
  - 精密定位: 高阻尼 (3.0-5.0)
  - 快速动作: 低阻尼 (0.5-1.5)

#### 3. 行程限制
**限制** (Limit)
- 范围: 0 - 1.1
- 默认值: 1.1
- 说明: 控制活塞的最大行程
- 特性:
  - 考虑活塞翻转状态
  - 限制超出设计行程
- 应用:
  - 精确控制: 较小限制
  - 最大行程: 默认限制

### 使用技巧

**精确定位活塞**
```
硬度: 高
阻尼: 4.0-5.0
限制: 0.5-0.8
```

**快速动作活塞**
```
硬度: 中等
阻尼: 0.5-1.0
限制: 1.0-1.1
```

**减震活塞**
```
硬度: 低
阻尼: 1.5-2.5
限制: 0.8-1.0
```

## 弹簧 (Spring) 增强功能

### 概述
弹簧增强功能为弹簧方块添加了阻力调节功能，使弹簧系统的物理行为更加真实和可控。

### 功能列表

#### 阻力控制
**阻力** (Drag)
- 范围: 0 - 3.0
- 默认值: 2.0
- 说明: 控制弹簧两端连接物体的阻力
- 影响:
  - 高阻力: 弹簧运动缓慢，稳定
  - 低阻力: 弹簧运动快速，可能震荡
- 应用:
  - 悬挂系统: 中等阻力 (1.5-2.5)
  - 快速弹射: 低阻力 (0.5-1.0)
  - 减震器: 高阻力 (2.5-3.0)

### 特性
- 同时调节两端物体的阻力
- 保持原有弹力系数不变
- 与其他物理参数协调工作

### 使用技巧

**悬挂弹簧**
```
阻力: 2.0-2.5
```

**弹射弹簧**
```
阻力: 0.5-1.0
```

**减震弹簧**
```
阻力: 2.5-3.0
```

## 铰链 (Hinge) 增强功能

### 概述
铰链增强功能为铰链方块添加了弹簧铰链功能，使铰链具有自动复位和阻尼特性。

### 功能列表

#### 1. 弹簧铰链系统
**弹簧开关** (Spring Toggle)
- 功能: 启用铰链的弹簧特性
- 特性:
  - 铰链会尝试回到初始位置
  - 可调节弹簧刚度和阻尼
  - 模拟真实门铰链

#### 2. 弹簧参数
**弹簧刚度** (Spring)
- 范围: 0 - 10.0
- 默认值: 1.0
- 实际值: 0 - 10000 (内部计算)
- 说明: 控制铰链的复位力
- 影响:
  - 高刚度: 强力复位
  - 低刚度: 柔和复位

**阻尼** (Damper)
- 范围: 0 - 10.0
- 默认值: 0.0
- 实际值: 0 - 10000 (内部计算)
- 说明: 控制铰链运动的阻尼
- 影响:
  - 高阻尼: 防止震荡
  - 低阻尼: 可能产生震荡

### 使用技巧

**门铰链**
```
弹簧开关: 启用
弹簧刚度: 5.0-8.0
阻尼: 2.0-4.0
```

**舱盖铰链**
```
弹簧开关: 启用
弹簧刚度: 3.0-5.0
阻尼: 1.0-2.0
```

**平衡铰链**
```
弹簧开关: 启用
弹簧刚度: 1.0-2.0
阻尼: 0.5-1.0
```

**标准铰链**
```
弹簧开关: 禁用
```

## 常见问题

### Q: 活塞运动不稳定？
A: 解决方案：
- 增加阻尼值
- 检查负载是否过重
- 调整硬度设置
- 检查行程限制

### Q: 弹簧震荡严重？
A: 优化建议：
- 增加阻力值
- 调整弹簧刚度
- 添加额外阻尼
- 检查连接方式

### Q: 铰链无法复位？
A: 检查事项：
- 确认弹簧开关已启用
- 增加弹簧刚度
- 检查是否被卡住
- 调整阻尼参数

### Q: 机械系统响应迟缓？
A: 改善方法：
- 降低阻尼值
- 减小硬度值
- 减轻负载
- 检查摩擦力设置

## 高级应用

### 液压悬挂系统
1. 活塞提供主支撑
2. 弹簧提供辅助支撑
3. 适当阻尼控制震荡
4. 铰链提供旋转自由度

### 精密定位系统
1. 高阻尼活塞精确定位
2. 弹簧铰链辅助定位
3. 高硬度确保稳定性
4. 低行程限制提高精度

### 减震系统
1. 弹簧吸收冲击
2. 活塞提供可控阻尼
3. 弹簧铰链辅助减震
4. 优化参数匹配

### 门禁系统
1. 弹簧铰链自动关门
2. 适当阻尼防止撞击

4. 高硬度确保耐用性

## 注意事项

1. **参数匹配**: 不同方块的参数需要协调匹配
2. **负载考虑**: 重负载需要更高刚度和阻尼
3. **稳定性**: 避免极端参数导致系统不稳定
4. **性能优化**: 合理设置参数避免性能问题
5. **保存设置**: 增强功能设置会保存在机器文件中
