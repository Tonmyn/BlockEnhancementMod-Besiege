# 悬挂 (Suspension) 增强功能说明

## 概述

悬挂增强功能为悬挂方块添加了液压控制模式、硬度调节、伸缩限制等高级功能，使其成为可编程的主动悬挂系统。

## 功能列表

### 1. 液压控制系统

#### 启用液压模式
- **开关**: Hydraulic Mode / 液压模式 (Pressure)
- 功能: 将被动悬挂转换为主动液压悬挂
- 特性:
  - 可以主动控制伸缩
  - 提供额外的推力
  - 实现可变悬挂高度

#### 液压控制按键

**伸展** (Extend)
- 默认按键: E
- 功能: 向伸展方向驱动悬挂
- 可自定义按键绑定

**收缩** (Retract)
- 默认按键: F
- 功能: 向收缩方向驱动悬挂
- 可自定义按键绑定

#### 自动复位
- **开关**: Return to Center / 回中
- 功能: 松开控制键后自动回到中间位置
- 特性:
  - 平滑过渡到中间位置
  - 避免突然复位
  - 保持悬挂稳定性

### 2. 硬度系统

#### 硬度调节
- **菜单**: Hardness / 硬度
- 选项: 金属硬度等级
- 功能: 调节悬挂的结构强度
- 影响:
  - 高硬度: 刚性悬挂，稳定性好
  - 低硬度: 柔性悬挂，舒适性好
- 应用:
  - 赛车悬挂: 高硬度
  - 越野悬挂: 中等硬度
  - 舒适悬挂: 低硬度

### 3. 行程控制

#### 伸展限制
- **滑块**: Extend Limit / 伸展限制
- 范围: 0 - 3.0
- 默认值: 1.0
- 说明: 控制悬挂最大伸展距离
- 应用:
  - 提高离地间隙
  - 增加通过性
  - 特殊地形适应

#### 收缩限制
- **滑块**: Retract Limit / 收缩限制
- 范围: 0 - 3.0
- 默认值: 1.0
- 说明: 控制悬挂最大收缩距离
- 应用:
  - 降低车身高度
  - 提高稳定性
  - 优化空气动力学

#### 实际行程
- 系统自动取两个限制值的最大值
- 确保双向行程一致
- 避免行程不对称

### 4. 驱动速度

#### 伸缩速度
- **滑块**: Feed Speed / 进给速度
- 范围: 0 - 2.0
- 默认值: 0.5
- 说明: 控制液压动作的速度
- 影响:
  - 高速度: 响应快速，但可能不稳定
  - 低速度: 平滑稳定，但响应慢
- 应用:
  - 快速调整: 高速度 (1.0-2.0)
  - 精确控制: 低速度 (0.2-0.5)
  - 标准操作: 中速度 (0.5-1.0)

## 常见问题

### Q: 悬挂不稳定，震荡？
A: 解决方案：
- 增加硬度值
- 降低伸缩速度
- 启用自动回中
- 检查负载分布

### Q: 液压响应迟缓？
A: 优化建议：
- 增加伸缩速度
- 检查按键绑定
- 确保液压模式已启用
- 检查系统性能

### Q: 行程不足？
A: 改善方法：
- 增加伸展/收缩限制值
- 检查物理限制
- 调整悬挂位置
- 考虑使用多个悬挂

### Q: 悬挂过硬或过软？
A: 调整建议：
- 调整硬度等级
- 根据负载优化
- 考虑用途选择
- 测试不同设置

### Q: 自动回中不工作？
A: 检查事项：
- 确认自动回中已启用
- 检查液压模式状态
- 验证按键配置
- 确保没有其他冲突

## 注意事项

1. **行程限制**: 避免设置过大行程导致机械干涉
2. **速度控制**: 极高的伸缩速度可能导致不稳定
3. **硬度匹配**: 悬挂硬度需要与车辆整体匹配
4. **液压压力**: 液压模式会增加系统复杂度
5. **保存设置**: 增强功能设置会保存在机器文件中
