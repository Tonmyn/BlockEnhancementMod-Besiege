## 功能列表

### 1. 导弹制导系统

#### 启用制导
- **开关**: Track Target / 跟踪目标
- **功能**: 将普通火箭转换为制导导弹
- **图片说明**: [截图：展示开启制导前后的对比]

#### 雷达系统设置

**雷达类型**
- `Passive Radar` (被动雷达): 自动搜索范围内的目标
- `Active Radar` (主动雷达): 需要手动锁定目标，提供更高的精确度
- **图片说明**: [截图：展示两种雷达模式的效果对比]

**搜索角度** (Search Angle)
- 范围: 0° - 90° (普通模式) / 0° - 175° (增强模式)
- 说明: 设置雷达的搜索扇区角度
- 建议: 宽角度用于广泛搜索，窄角度用于精确打击
- **图片说明**: [截图：展示不同搜索角度的可视化效果]

**搜索范围**
- 普通模式: 2000 米
- 增强模式: 5000 米
- **图片说明**: [截图：展示搜索范围的示意]

#### 主动雷达控制

**手动覆盖** (Manual Override)
- 默认按键: 右 Shift
- 功能: 切换主动雷达的手动/自动模式

**锁定目标** (Lock Target)
- 默认按键: Delete
- 功能: 手动锁定当前雷达范围内的目标
- **图片说明**: [截图：展示目标锁定界面]

**显示雷达** (Show Radar)
- 功能: 在游戏中显示雷达搜索范围的可视化
- **图片说明**: [截图：雷达范围显示效果]

**显示弹道预测** (Show Prediction)
- 功能: 显示导弹拦截目标的预测轨迹
- **图片说明**: [截图：弹道预测线显示]

**炮弹速度** (Projectile Speed)
- 范围: 0.1 - 1000
- 说明: 用于弹道预测计算的导弹速度设定

**炮弹阻力** (CannonBall Drag)
- 范围: 0 - 1
- 说明: 考虑空气阻力的弹道预测

### 2. 制导参数调整

**转向力矩** (Torque)
- 范围: 0 - 100
- 说明: 控制导弹的转向能力
- 建议: 高速导弹需要更大的转向力矩
- **图片说明**: [截图：不同转向力矩的效果对比]

**稳定性** (Stability)
- 开关: Rocket Stability / 火箭稳定性
- 功能: 启用空气动力学稳定性控制
- 适用: 高速飞行时的姿态控制

**制导延迟** (Guide Delay)
- 范围: 0 - 2 秒
- 说明: 发射后延迟启动制导系统
- 用途: 避免发射初期的不稳定
- **图片说明**: [截图：展示延迟制导的效果]

### 3. 引信系统

**撞击引信** (Impact Fuze)
- 开关: Impact Fuze / 撞击引信
- 触发条件: 低强度碰撞 (50 力)
- 说明: 敏感度更高，适合打击轻装甲目标
- **图片说明**: [截图：撞击引信爆炸效果]

**近炸引信** (Proximity Fuze)
- 开关: Proximity Fuze / 近炸引信
- **引爆距离** (Close Range): 0 - 10 米
- 说明: 当目标进入设定距离时自动引爆
- 适用: 对空防御和集群目标打击
- **图片说明**: [截图：近炸引信效果]

### 4. 发射控制

**自动释放** (Auto Release)
- 功能: 与抓取器配合使用，发射时自动释放火箭
- **图片说明**: [截图：自动释放效果]

**组发射** (Grouped Fire)
- 按键设置: 可自定义
- **发射速率** (Group Fire Rate): 0.1 - 1 秒
- 功能: 多枚火箭按设定间隔依次发射
- 用途: 创建弹幕或连续打击
- **图片说明**: [截图：组发射效果]

**单人队伍** (Single Player Team)
- 按键设置: 可自定义
- 功能: 在单人模式下模拟队伍识别

### 5. 视觉效果

**无烟模式** (No Smoke)
- 开关: No Smoke / 无烟模式
- 功能: 禁用火箭尾烟效果
- 优势: 提高性能，隐蔽发射
- **图片说明**: [截图：有烟/无烟对比]

**高爆模式** (High Explosive)
- 开关: High Explo / 高爆模式
- 功能: 增强爆炸效果和杀伤半径
- 注意: 爆炸装药量会被限制在 1.5 (普通) / 无限制 (增强模式)
- **图片说明**: [截图：普通/高爆效果对比]

### 6. 烟雾效果自定义

通过控制台命令可调整烟雾参数：

```bash
# 烟雾发射率
be srsecon [80.0]

# 烟雾持续时间
be srsl [1.0]

# 烟雾大小
be srss [3.5]

# 起始颜色 (RGB)
be srssc [0.1 0.14 0.15]

# 结束颜色 (RGB)
be srsec [0.1 0.14 0.15]

# 起始颜色时间
be srssct [0.09]

# 结束颜色时间
be srsect [1]

# 起始透明度
be srssa [1.0]

# 结束透明度
be srsea [1.0]

# 起始透明度时间
be srssat [0.076]

# 结束透明度时间
be srseat [0.26]
```

**图片说明**: [截图：展示不同烟雾参数的效果]

## 使用技巧

### 对空防御
1. 启用制导功能
2. 选择主动雷达模式
3. 设置较大的搜索角度 (60°-90°)
4. 启用近炸引信，设置适当的引爆距离 (3-5 米)
- **图片说明**: [截图：对空防御示例]

### 精确打击
1. 使用主动雷达
2. 减小搜索角度 (10°-30°)
3. 启用弹道预测显示
4. 设置适当的制导延迟 (0.3-0.5 秒)
- **图片说明**: [截图：精确打击示例]

### 防空导弹
1. 高转向力矩 (80-100)
2. 启用稳定性控制
3. 设置较短制导延迟 (0.1-0.2 秒)
4. 启用高爆模式
- **图片说明**: [截图：防空导弹拦截示例]

### 批量发射
1. 设置组发射按键
2. 调整发射速率 (0.2-0.5 秒)
3. 使用多个火箭并分配到同一组
4. 按住组发射按键实现齐射
- **图片说明**: [截图：批量发射效果]

## 常见问题

### Q: 导弹不追踪目标？
**图片说明**: [截图：问题示意图]

A: 检查以下几点：
- 确保已启用制导功能
- 主动雷达需要手动锁定目标
- 检查搜索角度和范围设置
- 确认目标在雷达范围内

### Q: 导弹提前引爆？
**图片说明**: [截图：近炸过早触发的例子]

A: 可能是近炸引信触发，尝试：
- 增加引爆距离
- 禁用近炸引信
- 使用撞击引信模式

### Q: 导弹转向不足？
**图片说明**: [截图：转向不足的例子]

A: 调整参数：
- 增加转向力矩值
- 减小导弹速度
- 启用稳定性控制

### Q: 火箭无法组发射？
A: 确认：
- 已设置组发射按键
- 火箭已分配到组
- 按住按键而不是点击

## 注意事项

1. **性能考虑**: 同时使用过多制导火箭可能影响性能
2. **多人游戏**: 某些功能在多人游戏中可能受限
3. **物理限制**: 极端的参数设置可能导致异常行为
4. **保存兼容性**: 增强功能的设置会保存在机器文件中
